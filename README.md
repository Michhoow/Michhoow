## Sobre mí

Desarrollador de software enfocado en **backend con .NET y C#**. Construyo APIs REST, modelo bases de datos relacionales y desarrollo la lógica de negocio que sostiene aplicaciones reales.

Trabajo principalmente con **ASP.NET Core**, **Entity Framework Core** y **SQL Server**, diseñando sistemas que resuelven problemas concretos: automatización de cálculos, gestión de inventario y procesamiento de datos de negocio.

Me interesa el backend bien hecho — código legible, consultas eficientes y sistemas que se puedan mantener y extender sin dolor.

- Desarrollo de **APIs REST** con ASP.NET Core
- Modelado y optimización de datos en **SQL Server** con EF Core
- Automatización de procesos y lógica de cálculo de negocio
- Control de versiones y colaboración con **Git / GitHub**
- Docencia técnica: impartí fundamentos de programación y algoritmos en el ITLA
